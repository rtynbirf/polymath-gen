# Архитектура ПОЛИМАТ-ГЕН

## Организм агента

```
                        ┌──────────────────────────────────────────┐
                        │              ЧЕЛОВЕК                     │
                        │   задание (текст / yaml, на русском)     │
                        └───────────────┬──────────────────────────┘
                                        ▼
┌───────────────┐   ┌─────────────────────────────────────────────┐
│  ПЛАНИРОВЩИК  │◄──┤  core/planner.py                            │
│  (раскадровка)│   │  image=1 кадр · storyboard=4 кадра · video  │
└───────┬───────┘   └─────────────────────────────────────────────┘
        ▼
┌─────────────────────────────────────────────────────────────────┐
│  ПРОМПТ-ДВИЖОК (соуслё?) core/prompt_engine.py                  │
│  • LLM-составление по кодексу лучших практик (patterns.json)     │
│  • метод REVE layout→render: скелет кадра из 8 зон в JSON        │
│  • fallback: словарь RU→EN + шаблоны стилей (работает без LLM)   │
└───────┬─────────────────────────────────────────────────────────┘
        ▼  positive + negative + layout
┌─────────────────────────────────────────────────────────────────┐
│  РУКИ  backends/                                                │
│  zai        картинки+видео через z-ai CLI (облако, уже работает)│
│  comfy      локальный ComfyUI: SDXL / FLUX.1 / Wan 2.2 / LTX    │
│  a1111      локальный WebUI Forge / A1111 API                   │
│  ffmpeg     сториборд-монтаж кадров в видео (xfade+zoompan)     │
└───────┬─────────────────────────────────────────────────────────┘
        ▼  результат
┌─────────────────────────────────────────────────────────────────┐
│  ГЛАЗА-КРИТИК  core/critic.py                                   │
│  VLM смотрит результат vs задание → JSON {score 1-10,           │
│  problems, fix_hints}. score < 7 → доработка промпта →          │
│  повторная генерация (до --rounds попыток)                      │
└───────┬─────────────────────────────────────────────────────────┘
        ▼
┌─────────────────────────────────────────────────────────────────┐
│  СБОРКА И ПАМЯТЬ                                                │
│  contact_sheet.png (сетка кадров) · storyboard.mp4 (ffmpeg)      │
│  state.json — полный отчёт: промпты, layout, оценки критика     │
└─────────────────────────────────────────────────────────────────┘
```

## Мозги (LLM-адаптеры)

| Адаптер | Где работает | Модель | Зачем |
|---|---|---|---|
| `llm/zai.py` | облако z-ai CLI (уже включено) | GLM | chat-составление промптов + vision-критика |
| `llm/ollama.py` | локально, офлайн | Qwen2.5 / Qwen2.5-VL | полная автономия без облака |

Один интерфейс: `.chat()`, `.vision()`, `.available`, `.extract_json()`.
Свой LLM = свой класс с этими четырьмя методами (10 строк).

## Поток данных прогона

`runs/<timestamp>/`
- `shot1_r1.png`, `shot1_r2.png` … — кадры по попыткам
- `contact_sheet.png` — контактный лист
- `storyboard.mp4` — видео (режим storyboard)
- `video.mp4` — генеративное видео (режим video)
- `state.json` — полная память прогона (промпты, layout, оценки критика, тайминги)

## Принципы (доктрина ПОЛИМАТ)

1. **Автономия**: человек ставит задачу текстом — агент сам планирует, составляет
   промпты, генерирует, оценивает себя и дорабатывает.
2. **Антигаллюцинация**: бэкенды проверяются на доступность; недоступное честно
   падает в fallback и помечается в отчёте; кодекс LLM запрещает выдумки о себе.
3. **Портативность**: облако z-ai работает сразу; полный офлайн-стек ставится
   скриптом `scripts/install_local_stack` (Windows PowerShell / Linux).
4. **Память**: каждый прогон — артефакт (state.json), данные для будущего
   дообучения LoRA (см. docs/FINETUNE.md).
