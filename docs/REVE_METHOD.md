> Источник: наше исследование архива **«Training Reve 2.0 at scale»**
> (app.reve.com/training-infra, снапшот сохранён локально: `download/reve-training-infra.zip`,

> команда переходит в OpenAI, код по email training-infra@reve.art).

## Суть метода

Генерация сложной сцены разбивается на два этапа:

```
задание → [ЭТАП 1: LAYOUT] структурный скелет кадра     → [ЭТАП 2: RENDER] финальный кадр
          зоны блоков + bbox [0..1] + содержимое каждой    рендер-промпт, согласованный
          зоны: фон / среда слева / среда справа /         со скелетом (субъект, свет,
          главный субъект / средний план / передний        атмосфера на своих местах)
          план / источник света / атмосфера
```

## Почему это работает

1. **Композиция перестаёт быть лотереей.** Модель получает не «нарисуй красиво», а
   пространственный план: что и где находится в кадре.
2. **Управляемость.** Хочешь передвинуть объект — двигаешь bbox в скелете, а не
   перебрасываешь кубики в промпте-одноразовке.
3. **Масштабируемость.** В «Training Reve 2.0 at scale» инфраструктура именно так и
   готовит данные для обучения: разложение сцены на структуру и рендер.

## Как это встроено в ПОЛИМАТ-ГЕН

- `PromptEngine.SYSTEM_PROMPT` (пункт 9 кодекса) требует от LLM-составителя
  вернуть `layout`: 6–10 блоков `{block, bbox [x,y,w,h] 0..1, content}`.
- Fallback-скелет `_layout_fallback()` даёт стандартные 8 зон даже без LLM.
- Каждый прогон сохраняет layout в `state.json` (поле `steps[].layout`) —
  это одновременно и документация замысла, и данные для будущего дообучения.
- Демонстрация метода руками: `examples/reve_method_demo/` — мы 08.11.2026
  сгенерировали картинку именно в два этапа (HTML/CSS-скелет → рендер), файлы
  `layout.json`, `step1_layout_skeleton.png`, `step2_final_render.png`.

## Применение в пайплайне агента

```
Задание человека → Planner (раскадровка) → PromptEngine (prompt + layout)
  → Backend (z-ai / ComfyUI) → Critic-глаза (VLM) → если score < 7
  → PromptEngine.refine (точечная правка промпта по замечаниям) → снова генерация
```
