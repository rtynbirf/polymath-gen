# ПАСПОРТ УЗЛА · polymath-gen

- Статус: активный узел роя ПОЛИМАТ. Версия: 0.1.0 (первый релиз с манифестом, волна 2026-11-08, W-AUD-11).
- Роль: автономный медиа-агент — задание человека → промпт → изображение/видео → самокритика → доработка.
- Кластер: swarm-agents (канон `polimat-hub/docpack/03_REESTR_REPO.md`).

## Здоровье узла

| Параметр | Значение | Кто стерегёт |
|---|---|---|
| CI | `.github/workflows/ci.yml` — pip install -e . + pytest | GitHub Actions, пины по полному SHA |
| Прививки | `.github/dependabot.yml` — pip + github-actions, еженедельно, группой | Dependabot |
| Манифест релиза | `SHA256SUMS.txt` в ассетах каждого релиза | волна приёмки `polimat-hub` |

## СЧЁТЧИК LLM-ПРОГОНОВ (урок TH-PM-10)

```
llm_run_counter: 0
llm_run_env: не указано (целевая среда не зафиксирована)
llm_run_last: —
```

**Правило:** код LLM-агента без прогона в целевой среде не считается выполненным.
Каждый успешный прогон LLM-контура в целевой среде инкрементирует `llm_run_counter`
и обновляет `llm_run_env`/`llm_run_last` коммитом с правдой в сообщении.
Поле артефакта, не украшение: счётчик читается приёмкой (`polimat-hub/docpack/09_PRIEMKA.md`).
